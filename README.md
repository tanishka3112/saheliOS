# saheliOS

> An AI-powered safety and mobility operating system for women.

## Vision

saheliOS aims to make commuting safer, smarter, and more accessible by combining artificial intelligence, retrieval-augmented generation (RAG), mapping technologies, and real-time community intelligence.

Instead of being just another navigation app, saheliOS is designed as an intelligent assistant that helps women travel with greater confidence.

---

## Planned Features

- AI-powered travel assistant
- Retrieval-Augmented Generation (RAG) knowledge system
- Safe route recommendations
- Crowd density prediction
- Women's safety heatmaps
- Anonymous community reporting
- Walking companion mode
- Accessibility-aware navigation
- Nearby emergency resources
- Smart travel recommendations
